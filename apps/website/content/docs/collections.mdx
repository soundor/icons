Each collection is a subpath of `@soundor/icons`, and so is each of its styles.
The collection's own subpath is its default style. There is no root export:
`import … from '@soundor/icons'` fails, so an app never pulls in a whole
catalog by accident.

The exact upstream versions are in the package's `generated/provenance.json`.

## Same names in every style

All styles of a collection use the same export names. To switch styles,
change the import path:

```tsx
import { Gear } from '@soundor/icons/phosphor'; // regular
import { Gear as GearBold } from '@soundor/icons/phosphor/bold';
import { PlayerPlay } from '@soundor/icons/tabler';
import { PlayerPlay as PlayerPlayFilled } from '@soundor/icons/tabler/filled';
```

A style that is missing an icon simply doesn't export it. Tabler's filled set
covers 1,054 of its icons, and Heroicons' micro set covers 316 of 324.
TypeScript reports the missing export.

Phosphor's React package takes the weight as a prop. Here each weight is a
subpath, because a prop would put all six weights of every icon in your
bundle.

## Names

An export is the upstream name in PascalCase:

| Upstream (collection)   | Export        |
| ----------------------- | ------------- |
| `play` (Lucide)         | `Play`        |
| `player-play` (Tabler)  | `PlayerPlay`  |
| `arrow-left` (Lucide)   | `ArrowLeft`   |
| `play_arrow` (Material) | `PlayArrow`   |
| `24-hours` (Tabler)     | `Icon24Hours` |
| `10k` (Material)        | `Icon10k`     |

A JavaScript name can't start with a digit, so names that would get an `Icon`
prefix. If two upstream names ever mapped to the same export, generation would
fail rather than drop one.

Each collection module also exports the types `IconProps`, `StrokeIconProps`
and `IconComponent`.

## What is not included

- **Lucide's deprecated aliases.** lucide-static ships extra files under old
  names, such as `alert-circle` for `circle-alert`. Only the current names are
  exported.
- **Material Symbols' other axes.** Material Symbols is a variable design with
  weight (100–700), grade (−25, 0, 200) and optical size (20–48). The package
  ships weight 400, grade 0 and optical size 24, in all three styles, unfilled
  and filled. Every combination would be about 600,000 components. Another
  weight would be a new set of subpaths, such as `material/w300`, and only
  needs a configuration entry.
- **Material Symbols' tags.** Google publishes them on fonts.google.com only,
  not in its repository, so the gallery searches Material Symbols by name.

No icon was left out or approximated because Soundor couldn't draw it. Every
icon in every style uses only paths, basic shapes, opacity and fill rules,
which Soundor's native SVG supports. The generator fails on anything else
(see [Soundor and the browser](/docs/renderers#what-soundor-draws)).
