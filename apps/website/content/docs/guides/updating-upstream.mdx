---
title: Updating upstream icons
description: Move a collection to a new upstream version and review what changed.
---

Upstream versions are pinned. Generated code is committed, so builds and CI
never fetch icon sources: `pnpm install && pnpm build` works offline once
dependencies are installed.

## npm collections

Lucide, Tabler, Phosphor and Heroicons:

1. Change the exact version in `pnpm-workspace.yaml`'s catalog, then run
   `pnpm install`. The workspace waits two days before installing a new
   release (`minimumReleaseAge`).
2. Run `pnpm generate`.
3. Review `git diff`. Each icon is one line, sorted by name, so the diff shows
   the icons added, changed and removed. A removed or renamed icon is a
   breaking change for anyone importing it.
4. Add a changeset (`pnpm changeset`): a minor version for new icons, a major
   one for removed or renamed icons.

## Material Symbols

Change `MATERIAL_COMMIT` in `packages/icons/scripts/sources/material.ts` to
a commit of google/material-design-icons, and continue from step 2. The first
run after a change fetches the commit's tree and the needed files into
`packages/icons/.cache/`, about 20 seconds.

## Checks

`pnpm generate --check` fails if the committed files differ from what the
pinned sources generate. CI runs it, so the generated code always matches its
sources. If generation fails on an icon, see
[Adding a collection](/docs/guides/adding-a-collection) for what to do instead
of skipping it.
