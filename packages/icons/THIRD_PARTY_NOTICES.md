# Third-party notices

The icons in this package are artwork from the open-source projects below,
converted from their SVG files to JavaScript modules for Soundor and React
DOM. The conversion keeps each icon's geometry and changes its file format.
Each collection stays under its own license, whose full text is in
`licenses/`; the MIT license in `LICENSE` covers Soundor Icons' own code
(`dist/` and the generator), not the artwork.

Exact versions, and the normalizations the conversion applied, are in
`generated/provenance.json`.
