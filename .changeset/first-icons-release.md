Release Lucide, Tabler, Phosphor, Heroicons and Material Symbols as React components for Soundor plugins and the browser, one subpath per collection and style. The `soundor` export condition selects native SVG from `@soundor/react/svg` in Soundor builds; every other environment gets React DOM `<svg>`. The upstream licenses are in `licenses/`.
